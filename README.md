# 就活管理 PWA

就職活動の企業・選考ステータス・予定（ES締切や面接）を管理する PWA です。
ビルド不要の HTML / CSS / JavaScript だけで動き、GitHub Pages でそのまま公開できます。

## 機能
- **ホーム**: 選考中の社数・直近の予定（期限切れも表示）・予定が未登録の企業・選考状況の内訳
- **企業**: ステータス・東京勤務・業界・エントリー経路での絞り込み、検索、並び替え
- **企業の詳細**: ステータスのワンタップ変更（選考履歴を自動記録）、マイページ・ID・パスワードへのショートカット、予定・締切、職種ごとの条件、ES・面接メモ
- **募集要項の自動入力**: 採用サイトの募集要項をコピーして貼り付けるだけで各項目に入力、業界も自動推定
- **複数職種**: 同じ会社の職種・コースごとに勤務地・東京勤務・条件を登録
- **比較**: 初任給・住宅補助・年間休日などを職種単位でグラフ・一覧表で比較
- **予定**: 全社の予定一覧、Google カレンダー追加リンク、.ics でカレンダーアプリへ一括書き出し
- **ログイン情報**: 就活サービス（マイナビ・リクナビ など）と企業マイページの URL・ID・パスワード
- **ESストック**: 自己PR・ガクチカなどの文章を文字数つきで保存し、ES・面接メモから呼び出し
- **業界ガイド**: 業界の分類と説明
- JSON でのバックアップ書き出し / 読み込み、オフライン動作、ダークモード

## データについて
データはブラウザの localStorage（端末内）にのみ保存され、サーバーには送信されません。
ID・パスワードもこの端末内にそのまま保存されます。バックアップファイルにもパスワードが含まれるので、取り扱いに注意してください。
端末を変えるときは「設定 → バックアップを書き出す」で移行してください。

## ローカルで動かす
```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## GitHub Pages で公開
1. GitHub にリポジトリを作成して push
2. Settings → Pages → Source: `Deploy from a branch`、Branch: `main` / `/ (root)` を選択
3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 更新時の注意
ファイルを変更したら `sw.js` の `CACHE_VERSION` を上げてください。
