# 就活管理 PWA

就職活動の企業・選考ステータス・予定（ES締切や面接）を管理する PWA です。
ビルド不要の HTML / CSS / JavaScript だけで動き、GitHub Pages でそのまま公開できます。

## 機能
- **ホーム**: 選考中の社数・**今日やること**（Gmailの要返信メール、今日・明日の予定の準備、結果待ちが長い企業、予定が未登録の企業）・直近の予定・選考状況の内訳
- **志望度の仕分け**: 「興味あり」の企業をカードでスワイプ（右=受けたい★3 / 上=保留 / 左=受けない→辞退）。戻すこともできる
- **クイック追加**: 企業名と進み具合・志望度をタップで選ぶだけで登録。企業名を1行ずつ貼り付けてまとめて登録も可
- **企業**: ステータス・東京勤務・業界・エントリー経路での絞り込み、検索、並び替え
- **企業の詳細**: ステータスのワンタップ変更（選考履歴を自動記録）、マイページ・ID・パスワードへのショートカット、予定・締切、職種ごとの条件、ES・面接メモ
- **募集要項の自動入力**: 採用サイトの募集要項をコピーして貼り付けるだけで各項目に入力、業界も自動推定
- **Gmailから自動で取り込む**: 自分の Google アカウントに置いたスクリプト（`gas/`）が採用メールを読み、企業・選考の進み具合・面接日・マイページの URL/ID をアプリに同期（既存の内容は上書きせず、ステータスは先に進める方向だけ反映）
- **採用ページから取り込む（ブックマーク）**: 募集要項・マイページを開いてブックマークを押すだけで、ページの文章を読み取って企業の登録画面に入力（企業名・URL も自動。登録済みの企業なら照合して追記）
- **複数職種**: 同じ会社の職種・コースごとに勤務地・東京勤務・条件を登録
- **比較**: 初任給・住宅補助・年間休日などを職種単位でグラフ・一覧表で比較
- **予定**: 全社の予定一覧、Google カレンダー追加リンク、.ics でカレンダーアプリへ一括書き出し
- **ログイン情報**: 就活サービス（マイナビ・リクナビ など）と企業マイページの URL・ID・パスワード
- **ESストック**: 自己PR・ガクチカなどの文章を文字数つきで保存し、ES・面接メモから呼び出し
- **業界ガイド**: 業界の分類と説明
- **PC のブラウザ対応**: 広い画面では左サイドバー、企業一覧と詳細の2画面表示、編集画面の2列表示
- JSON でのバックアップ書き出し / 読み込み（PCとスマホのデータを消さずに統合できる）、オフライン動作、ダークモード

## データについて
データはブラウザの localStorage（端末内）にのみ保存され、サーバーには送信されません。
ID・パスワードもこの端末内にそのまま保存されます。バックアップファイルにもパスワードが含まれるので、取り扱いに注意してください。
端末を変えるときは「設定 → バックアップを書き出す」で移行してください。

## Gmail 同期の設置
1. https://script.google.com で新しいプロジェクトを作り、`gas/gmail-sync.gs` の内容を貼り付ける
2. プロジェクトの設定で「appsscript.json を表示」をオンにし、`gas/appsscript.json` の内容に置き換える（Gmail は読み取り専用の権限だけを使う）
3. 「デプロイ → 新しいデプロイ → ウェブアプリ」（実行：自分 / アクセス：全員）
4. 関数 `setup` を実行し、ログに出た `…/exec?token=…` をアプリの「その他 → Gmailから自動で取り込む」に貼り付ける

最初は過去 240 日分を少しずつ読み、以降は 1 時間ごとに新しいメールを読みます。読み直すときは `resetSync` → `setup`。

## ローカルで動かす
```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## GitHub Pages で公開
1. GitHub にリポジトリを作成して push
2. Settings → Pages → Source: `Deploy from a branch`、Branch: `main` / `/ (root)` を選択
3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 更新時の注意
ファイルを変更したら `sw.js` の `CACHE_VERSION` を上げてください。
