    📬 Gmailから自動で取り込む

    Gmail に届いた採用メールから、企業・選考の進み具合・面接日・マイページのURL/IDを自動で登録します。自分の Google アカウントに専用のスクリプトを1回設置すると使えます（Gmail は読み取り専用。データは外部に送りません）。

    設置のしかた（最初に1回・5分）
    1. PC のブラウザで script.google.com を開く（新しいプロジェクトが作られます）。左上の名前を「就活管理 Gmail同期」に変える
    2. を押し、エディタの「コード.gs」の中身を全部消して貼り付け → 保存（💾）。関数の選択に「setup」が出ればOK
    3. 左の ⚙️「プロジェクトの設定」→「appsscript.json マニフェスト ファイルをエディタで表示する」にチェック → エディタに戻って appsscript.json を開き、 した内容に全部置き換えて保存
    4. 右上「デプロイ」→「新しいデプロイ」→ ⚙️ で「ウェブアプリ」を選ぶ → 次のユーザーとして実行「自分」、アクセスできるユーザー「全員」→「デプロイ」（すでにデプロイ済みでコードを貼り直したときは「デプロイを管理」→ ✏️ → バージョン「新バージョン」→「デプロイ」）。Google のログインと許可の画面が出たら許可する（「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」）
    5. 上の関数の選択で「setup」を選んで「実行」→ 下の実行ログに出たトークンを確認 →「デプロイを管理」の「ウェブアプリ」の URL（…/exec で終わるもの）の後ろに ?token=… を付けて、この画面の「同期用 URL」に貼り付ける（…/dev の URL は使えません）

    最初は過去8か月分を読むので、全部そろうまで数時間かかることがあります（1時間ごとに自動で続きを読みます）。同期用 URL を知っている人は企業名やマイページIDを見られるので、人に教えないでください。

    📥 就活管理に取り込む

      表示

      🤖 Claude 用の入力の型

      Claude に「入力の型」と募集要項を送ると、このアプリに貼り付けるだけで入力できる答えを返してくれます。Claude のプロジェクトを作って「指示」に入力の型を入れておくと、次からは募集要項を送るだけで済みます。

      答えの貼り付け先：企業の編集画面の「コピーした答えを貼り付け」、企業を追加の「Claude の答えを貼り付けて登録」（複数社をまとめて登録できます）、PC は一覧画面で Ctrl+V。
      入力の型には学歴・卒業年度が入っています。設定を変えたらコピーし直してください。

      ☁️ PCとスマホで同じデータを使う

      変更するたびに自分の Google ドライブ（「就活管理アプリのバックアップ」フォルダ）へ自動で保存し、もう片方の端末で開くと最新の内容になります。両方で変更したときは統合するので、どちらの変更も消えません。毎日のバックアップも60日分残ります。

      バックアップから戻す

      使うには「Gmailから自動で取り込む」の同期用 URL と、最新のスクリプト（v4・Google ドライブの許可）が必要です。

      データ

      データはこの端末のブラウザ内に保存され、「PCとスマホで同じデータを使う」をオンにすると Google ドライブにも保存されます。ファイルに書き出して手元に残すこともできます。読み込むときに「追加・統合」を選べば、この端末のデータは消えません。
      ※ バックアップにはパスワードもそのまま含まれるので、人に渡したり公開しないでください。

      このアプリについて

      ホーム画面に追加するとアプリとしてオフラインでも使えます。
      iPhone: Safari の共有ボタン →「ホーム画面に追加」
